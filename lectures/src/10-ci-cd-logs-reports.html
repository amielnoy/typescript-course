בדיקה נכשלה ב-CI בשלוש בלילה. מה עכשיו?

  • אין מסך, אין דיבאגר – נשארו רק הראיות: 📝 לוגים · 📸 צילומי מסך / Trace · 📦 תשובות השרת · 📊 דוח
  • המטרה: לענות מהר על באג במוצר? באג בבדיקה? בעיית סביבה? – לכל תשובה פעולה אחרת

🐞 באג במוצר

השרת מחזיר role: "tester" למשתמש שאמור להיות admin, אחרי שינוי בהרשאות.

פעולה: פותחים באג למפתחים, מצרפים את הראיות.

🧪 באג בבדיקה

הבדיקה מצפה ל-3 משתמשים, אבל בדיקה אחרת יצרה משתמש רביעי באותה סביבה.

פעולה: מתקנים את הבדיקה / את ניהול הנתונים.

🌐 בעיית סביבה

ECONNREFUSED או timeout – השרת לא עלה, שירות חיצוני נפל, DNS.

פעולה: מטפלים בסביבה ומריצים שוב. לא פותחים באג במוצר.

את ההחלטה מקבלים רק מתוך הראיות. ראיות חלשות = שעות של ניחושים, או באג שנפתח בטעות למפתחים.

רמות לוג – מתי משתמשים בכל אחת

רמהמתידוגמה מעולם הבדיקותמוצגת ב-CI?
debugפרטים קטנים, רק כשמחפשים באגFilling username fieldרק עם LOG_LEVEL=debug
infoהצעדים העיקריים של הבדיקהPOST /api/login → 200 (143ms)כן (ברירת מחדל)
warnמשהו חשוד, אבל הבדיקה ממשיכהResponse slower than expected: 2300msכן
errorכישלון / חריגהAssertion failed: expected 3 items, got 2תמיד
הרמות מסודרות: debug < info < warn < error. בוחרים "רמה מינימלית" – וכל מה שמתחתיה לא מודפס.
כלל אצבע: אם הבדיקה עברה – מספיק לראות info. אם נכשלה – רוצים debug.

לוג טוב

    class Logger {
      constructor(private context: string, private minLevel: Level = levelFromEnv("info"), private filePath?: string) {}
      child(sub: string) { return new Logger(`${this.context}:${sub}`, this.minLevel, this.filePath); }
      info(msg: string, data?: unknown) { this.write("info", msg, data); }
      error(msg: string, data?: unknown) { this.write("error", msg, data); }

      private write(level: Level, msg: string, data?: unknown) {
        if (ORDER[level] < ORDER[this.minLevel]) return;
        const line = `[${new Date().toISOString()}] [${level.toUpperCase()}] [${this.context}] ${msg}`
                   + (data !== undefined ? ` ${JSON.stringify(data)}` : "");
        console.log(line);
        if (this.filePath) appendFileSync(this.filePath, line + "\n");
      }
    }

    const log = new Logger("suite", "debug", "reports/logs/run.log").child("cart");
    log.error("Assertion failed: expected 3 items, got 2", { cartId: "c-981" });
    // [2026-01-01T02:14:07.112Z] [ERROR] [suite:cart] Assertion failed: ... {"cartId":"c-981"}
  • מתי – timestamp ב-ISO
  • כמה חמור – debug / info / warn / error
  • איפה – context (סוויטה:בדיקה)
  • מה – הודעה + נתונים
  • רמת לוג דרך LOG_LEVEL
  • לא לרשום סיסמאות וטוקנים!

    const SECRET_KEYS = ["password", "token", "authorization"];
    function redact(data: Record<string, unknown>): Record<string, unknown> {
      const copy: Record<string, unknown> = {};
      for (const [key, value] of Object.entries(data)) {
        copy[key] = SECRET_KEYS.includes(key.toLowerCase()) ? "***" : value;
      }
      return copy;
    }
    const log = new Logger("login");

    log.info("POST /login (bad)", body);

    log.info("headers", redact({ Authorization: "Bearer eyJhbGci", Accept: "json" }));

מה זה Reporter? – ו-Reporters מובנים ב-node:test

ה-runner מריץ ואוסף תוצאות. ה-Reporter מחליט איך להציג/לשמור אותן – לבני אדם או למכונות (CI).

dot.XXX – תו לכל בדיקהבני אדםהרבה בדיקות, פלט קצר

ה-exit code של הסקריפט: 1 → השלב אדום

      interface RunStats {
        total: number; failed: number; skipped: number; passRate: number;
      }

      function qualityGate(s: RunStats): string[] {
        const problems: string[] = [];
        if (s.failed > 0) problems.push(`${s.failed} failed test(s)`);
        if (s.passRate < 95)
          problems.push(`pass rate ${s.passRate}% < 95%`);
        if (s.skipped / s.total > 0.2)
          problems.push(`too many skipped: ${s.skipped}/${s.total}`);
        return problems;
      }

      const problems = qualityGate({
        total: 40, failed: 1, skipped: 10, passRate: 97,
      });
      if (problems.length) {
        console.log(`❌ quality gate failed:\n- ${problems.join("\n- ")}`);
        process.exit(1);
      }
      console.log("✅ quality gate passed");
