הרצהNode.js או דפדפן
  • TypeScript = JavaScript + מערכת טיפוסים. כל קוד JS תקין הוא גם TS תקין
  • הטיפוסים קיימים רק בזמן כתיבה וקומפילציה – בזמן ריצה רץ JavaScript רגיל
  • קומפילציה = תרגום. הדפדפן ו-Node.js מבינים רק JavaScript
כלימה הוא עושהמתי נשתמש

למה צריך טיפוסים? אותו באג – פעמיים

ב-JavaScript: הערך הגיע מקובץ הגדרות כטקסט – והחיבור "עובד", אבל לא כמו שציפינו

      const timeout = "5000";       // טקסט, לא מספר!
      const total = timeout + 1000; // ציפינו ל-6000
      console.log(total);
    
      50001000

ב-TypeScript: מצהירים שזה מספר – והעורך מסמן שגיאה עוד לפני ההרצה

      const timeout: number = "5000";
    
      error TS2322: Type 'string' is not assignable to type 'number'.
בבדיקה אמיתית באג כזה היה מתגלה רק בזמן ריצה (timeout של 50 מיליון ms...). TS תופס אותו בעורך.

משתנים: const ו-let

  • משתנה = שם לערך, כדי להשתמש בו שוב
  • ברירת מחדל: const – אי אפשר להציב ערך חדש
  • let רק כשהערך באמת משתנה (מונה, ניסיונות)
  • לא להשתמש ב-var (התנהגות ישנה ומבלבלת)
  • שמות באנגלית, camelCase: maxRetries, baseUrl
        const baseUrl = "https://api.example.com"; // לא משתנה
        let retries = 0;                           // ניתן לשנות
        retries = retries + 1;
        retries++;
        console.log(baseUrl, "retries:", retries);

        // baseUrl = "x";
        // ❌ Cannot assign to 'baseUrl' because it is a constant.

        const user = { name: "Dana", age: 29 };
        user.age = 30; // ✅ מותר – רק ההצבה מוגנת
        console.log(user);
      
        https://api.example.com retries: 2
        { name: 'Dana', age: 30 }

טיפוסים בסיסיים: string, number, boolean

  • string – טקסט: שם בדיקה, URL, הודעת שגיאה
  • number – כל מספר: שלם או עשרוני (אין int/float נפרדים)
  • boolean – true / false: עבר? headless?
  • לטקסט יש כלים מובנים: .length, .toUpperCase()
  • Number("5000") – ממיר טקסט למספר
  • typeof x – שם הטיפוס כטקסט. מלכודת: null ומערך → "object"
        const testName: string = "Login with valid user";
        const durationMs: number = 1532.5;
        const isPassed: boolean = true;

        console.log(typeof testName, typeof durationMs, typeof isPassed);
        console.log(testName.length, testName.toUpperCase());
        console.log(durationMs / 1000, "seconds");
        console.log(Number("5000") + 1000);
        console.log(typeof null, typeof [1, 2]); // מלכודת!
      
        string number boolean
        21 LOGIN WITH VALID USER
        1.5325 seconds
        6000
        object object

Type Inference – מתי בכלל צריך לכתוב טיפוס?

  • TS מסיק את הטיפוס מהערך ההתחלתי – לא חייבים לכתוב אותו
  • הטיפוס נקבע פעם אחת ונשאר: אי אפשר לשים מספר במשתנה טקסט
  • כותבים טיפוס כשאין ערך התחלתי, או כשרוצים להיות מפורשים
  • טיפ: ב-VS Code עמדו עם העכבר על משתנה כדי לראות את הטיפוס
        let browser = "chromium";
        // browser = 42; ❌ Type 'number' is not
        //                  assignable to type 'string'.
        let lastStatus: number; // אין ערך עדיין
        lastStatus = 404;

אובייקטים (Objects)

  • מקבץ שדות בעלי שם – למשל תוצאה של בדיקה אחת

any מול unknown – כשלא יודעים מה הטיפוס

❌ any – "סמוך עליי"

TS מפסיק לבדוק לגמרי. הטעות מתגלה רק בזמן ריצה

        let anything: any = 5;
        console.log("before crash");
        anything.toUpperCase(); // TS לא מתריע...
      
        before crash
        TypeError: anything.toUpperCase is not a function

✅ unknown – "בדוק לפני שימוש"

TS מכריח לבדוק מה יש בפנים (למשל תשובה מ-API)

        const body: unknown = JSON.parse('{"id": 7}');
        // body.id;  ❌ 'body' is of type 'unknown'

        if (typeof body === "object" && body !== null &&
            "id" in body) {
          console.log("id:", (body as { id: number }).id);
        }
      
        id: 7
כלל אצבע: לא משתמשים ב-any. as אומר ל-TS "סמוך עליי, זה הטיפוס" – נרחיב בהמשך

null, undefined ו"או" ( | )

  • null – "אין ערך", בכוונה (עוד לא שויך מטפל לבאג)
  • undefined – "לא הוגדר": משתנה בלי ערך, שדה שלא קיים
  • string | null – Union: אחד מהטיפוסים
  • timeout?: number – שדה אופציונלי (יכול להיות חסר)
TS לא ייתן להשתמש בערך שעלול להיות null בלי לבדוק קודם
        let assignee: string | null = null;
        console.log("assignee:", assignee);
        assignee = "Yossi";
        console.log("assignee:", assignee);

        let finishedAt: number | undefined;
        console.log("finishedAt:", finishedAt);

        const config: { browser: string; timeout?: number } = {
          browser: "chromium",
        };
        console.log("timeout:", config.timeout);
      
        assignee: null
        assignee: Yossi
        finishedAt: undefined
        timeout: undefined

אופרטורים אריתמטיים – ומלכודות של +

  • + - * / – כמו במחשבון · % – שארית · ** – חזקה

  • x++ – הוסף 1 · x += 5 – קיצור של x = x + 5

?? מול || – ערך ברירת מחדל

  • a ?? b – אם a הוא null/undefined → b
  • a || b – אם a "שקרי" (גם 0, "", false) → b
  • לברירות מחדל של הגדרות – תמיד ??
        const envTimeout: number | undefined = undefined;
        const timeout = envTimeout ?? 30_000;
        console.log("timeout:", timeout);

        const retries: number = 0; // ביקשו במפורש 0
        console.log("|| :", retries || 3); // ❌
        console.log("?? :", retries ?? 3); // ✅
      
        timeout: 30000
        || : 3
        ?? : 0

switch – השוואה לרשימת ערכים

  • משווה ערך אחד מול ערכים מדויקים (===) · לטווחים (>= 400) – if
  • case – ערך אפשרי (כמה ברצף – אותו קוד) · break – יציאה · default – כמו else

✅ עם break – רק ה-case המתאים

        const browser: string = "chrome";
        switch (browser) {
          case "chromium":
          case "chrome": // שני case-ים לאותו קוד
            console.log("Running on Chromium engine");
            break;
          case "firefox":
            console.log("Running on Gecko engine");
            break;
          default: console.log("Unknown browser");
        }
      
        Running on Chromium engine

❌ שכחתי break – "נופל" לכל ה-case-ים הבאים

        const env: string = "staging";
        switch (env) {
          case "staging":
            console.log("url: staging.example.com");
          case "production":
            console.log("url: www.example.com");
          default: console.log("url: localhost");
        }

switch על enum

  • switch ו-enum – זוג מושלם: רשימה סגורה של מקרים
  • P1 = 1 – הבאים ממשיכים אוטומטית: P2=2, P3=3
  • TS מתריע אם כתבתם case עם ערך שלא קיים ב-enum
  • הפונקציה מדמה ערך שמגיע ממערכת ניהול באגים
        enum Priority { P1 = 1, P2, P3 } // 1, 2, 3
        // מדמה ערך שמגיע ממערכת ניהול באגים
        function getPriorityFromJira(): Priority {
          return Priority.P2;
        }
        const bugPriority = getPriorityFromJira();

        switch (bugPriority) {
          case Priority.P1:
            console.log("Fix immediately – blocks release");
            break;
          case Priority.P2:
            console.log("Fix in current sprint");
            break;
          case Priority.P3:
            console.log("Add to backlog");
            break;
        }
      
        Fix in current sprint

for...in – מעבר על מפתחות של אובייקט

  • בכל סיבוב מקבלים שם של שדה (מפתח)
  • את הערך שולפים עם config[key]
  • Record<string, ...> – אובייקט עם מפתחות טקסט וערכים מטיפוס מסוים
על מערך, for...in מחזיר אינדקסים כטקסט: "0", "1". למערכים – for...of
        const config: Record<string, string | number | boolean> = {
          browser: "chromium",
          headless: true,
          retries: 2,
        };

        for (const key in config) {
          console.log(`${key} = ${config[key]}`);
        }
      
        browser = chromium
        headless = true
        retries = 2
